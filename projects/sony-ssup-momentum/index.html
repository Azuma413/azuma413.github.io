Sony SSUP: Real-time Momentum Visualization

Developed a system for Sony SSUP that visualizes human momentum in real-time using IMUs, a lightweight CNN, and a biomechanical model.

Overview For Sony's SSUP program, I developed a system that visualizes human momentum in real time, with potential applications in sports science and rehabilitation. Key Technologies Uses a Sony Spresense board with multiple IMU sensors. Time series data from the IMUs are fed into a lightweight CNN to classify motion (e.g., "walking"). This classification, combined with a biomechanical model, is used to calculate and visualize the user's momentum. YouTube Demo
